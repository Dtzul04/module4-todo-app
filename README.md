- JavaScript (vanilla)

---

## 📦 How to Run
1. Clone the repo: git clone [repo-url]
2. Open the folder in Visual Studio Code.
3. Right-click `index.html` and choose **Open with Live Server**.
4. Type a task and click **Add Task**.
